Materi 1 · Konsep Dasar

Apa Itu Fungsi Invers?

Bayangkan fungsi sebagai mesin: kita memasukkan x, mesin mengolah, dan mengeluarkan y. Fungsi invers adalah mesin "undo"-nya — memasukkan hasil y dan mengembalikannya menjadi x semula. Karena itu f⁻¹ sering disebut pemetaan balik.

Definisi Formal

Diketahui fungsi f : A → B yang bijektif. Fungsi invers f⁻¹ : B → A adalah fungsi yang memetakan setiap b ∈ B kembali ke a ∈ A yang asalnya memetakan ke b.

f(a) = b  ⇔  f⁻¹(b) = a

Notasi f⁻¹ dibaca "f invers". Domain dan range saling bertukar: D(f⁻¹) = R(f) dan R(f⁻¹) = D(f). Inilah alasan arah pemetaan f⁻¹ berlawanan dengan f.

Syarat: Harus Bijektif

Agar inversnya berupa fungsi (setiap b punya satu pasangan balik), f harus bijektif — injektif sekaligus surjektif:

SifatArtiJika Tidak?
Injektif (satu-satu)dua input berbeda → output berbedaarah balik jadi ambigu
Surjektif (onto)semua elemen B mendapat pasanganada yang tak terpetakan balik
Bijektifinjektif + surjektif— syarat terpenuhi

Contoh cepat: f(x) = x² pada ℝ tidak punya invers karena f(2) = f(−2) = 4 — pemetaan banyak-ke-satu. Namun jika domainnya dibatasi x ≥ 0, f menjadi bijektif dan inversnya adalah f⁻¹(x) = √x.

Awas miskonsepsi! f⁻¹(x) bukan 1/f(x). Notasi pangkat −1 di sini berarti "pemetaan balik", bukan kebalikan nilai. Contoh: f(x) = 2x + 3 memiliki f⁻¹(x) = (x − 3)/2, sedangkan 1/f(x) = 1/(2x + 3) — keduanya jelas berbeda. Sebaliknya, hubungan yang benar adalah f⁻¹(f(x)) = x: fungsi invers "membatalkan" efek fungsi asalnya.
Empat sifat kunci yang dipakai terus-menerus: (1) f(f⁻¹(x)) = x dan f⁻¹(f(x)) = x — saling membatalkan; (2) (f⁻¹)⁻¹ = f — invers dari invers adalah fungsi asal; (3) f(a) = b ⇔ f⁻¹(b) = a — tukar cepat tanpa menghitung rumus; (4) D(f⁻¹) = R(f) — domain dan range bertukar peran.

Melihat Invers sebagai Pemetaan Balik

Fungsi f(x) = 2x + 2 memetakan himpunan A = {0, 1, 2, 3} ke himpunan B = {2, 4, 6, 8}. Tekan tombol di bawah untuk memetakan maju (f) dan balik (f⁻¹), lalu amati arah panahnya berubah.

Simulasi 1 · Pemetaan Maju & Balik
Klik salah satu tombol di atas untuk memulai pemetaan. Perhatikan baik-baik arah panah pada tiap mode.

Yang Terlihat Saat Memetakan f

Panah bergerak maju: 0 → 2, 1 → 4, 2 → 6, 3 → 8. Setiap elemen B menerima tepat satu panah — itulah wajah fungsi injektif dan surjektif (bijektif). Rumusnya f(x) = 2x + 2, dan misalnya f(3) = 2(3) + 2 = 8.

Yang Terlihat Saat Memetakan f⁻¹

Panah berbalik arah: 2 → 0, 4 → 1, 6 → 2, 8 → 3. Inversnya adalah f⁻¹(x) = (x − 2)/2. Contoh: karena f(3) = 8 maka f⁻¹(8) = 3. Perhatikan pula: domain f⁻¹ = {2, 4, 6, 8} = range f — persis sifat pertukaran domain–range.

Intuisi penting: jika panah f digambar lalu panah f⁻¹ digambar tepat di atasnya dengan arah berlawanan, keduanya "saling meniadakan" — angka kembali ke asalnya. Itulah makna f⁻¹(f(x)) = x. Grafik kedua fungsi juga akan saling bercermin terhadap garis y = x (dibuktikan pada simulasi grafik logaritma di Materi 5).

Materi 2 · Teknik Dasar

Empat Langkah Menginverskan Fungsi

Metode paling aman untuk mencari f⁻¹ dari fungsi apa pun adalah metode aljabar empat langkah. Ide intinya satu kalimat: input dan output saling bertukar peran, lalu kita selesaikan persamaannya.

Empat Langkah (Contoh Berjalan: f(x) = 2x + 3)

1
Misalkan y = f(x)
y = 2x + 3
Ganti notasi f(x) dengan y agar mudah dipindah-pindah ruasnya.
2
Tukar peran x dan y
x = 2y + 3
Inilah inti invers: yang tadinya masukan menjadi keluaran, dan sebaliknya.
3
Selesaikan untuk y
x − 3 = 2y  →  y = x − 32
Pindahkan +3 (ganti tanda), lalu bagi kedua ruas dengan 2. Tujuan akhir: y sendirian di ruas kiri.
4
Tulis sebagai f⁻¹(x)
f⁻¹(x) = x − 32
Selesai! Ganti y dengan notasi inversnya.

Verifikasi & Trik Cepat

Uji jawabanmu dengan sifat saling-membatalkan:

f(f⁻¹(x)) = 2 · x − 32 + 3 = (x − 3) + 3 = x ✓

Jika hasilnya bukan x, pasti ada kesalahan hitung — biasanya di tanda. Trik cepat untuk soal nilai: tidak perlu mencari rumus f⁻¹ dulu! Karena f(4) = 11, maka otomatis f⁻¹(11) = 4. Hubungan f(a) = b ⇔ f⁻¹(b) = a menyelesaikan banyak soal dalam satu baris.

Jembatan keledai bentuk linear: untuk f(x) = ax + b, inversnya f⁻¹(x) = (x − b)/a — "b pindah ruas ganti tanda, a turun menjadi pembagi". Contoh: f(x) = 5x + 2 → f⁻¹(x) = (x − 2)/5.
Mengapa langkah 2 (menukar x dan y) sah? Karena f⁻¹ didefinisikan lewat hubungan f(a) = b ⇔ f⁻¹(b) = a: pasangan (a, b) milik f menjadi pasangan (b, a) milik f⁻¹. Menukar x dan y persis mewakili penukaran pasangan tersebut — itulah alasan matematisnya, bukan sekadar trik hafalan.

Materi 3 · Rumus Cepat

Tabel Rumus Invers Cepat

Setelah terbiasa dengan empat langkah, rumus-rumus berikut mempercepat pengerjaan soal pilihan ganda. Pelajari kolom "cara cepat" — di situlah logika rumusnya, bukan sekadar hafalan.

Tujuh Rumus yang Paling Sering Keluar

Bentuk fungsiInversnyaCara cepat & contoh
f(x) = ax + bf⁻¹(x) = x − bab pindah ruas ganti tanda, a jadi pembagi. Contoh: f(x) = 3x + 5 → f⁻¹(x) = (x − 5)/3
f(x) = ax + bcx + df⁻¹(x) = −dx + bcx − a−d dan −a bertukar posisi; b, c tetap. Contoh: f(x) = (2x + 3)/(x − 4) → f⁻¹(x) = (4x + 3)/(x − 2)
(f∘g)(x) = ax + b(f∘g)⁻¹(x) = x − baKomposisi diperlakukan seperti satu fungsi. Contoh: (f∘g)(x) = 6x − 1 → (f∘g)⁻¹(x) = (x + 1)/6
f(x) = aᵣf⁻¹(x) = alog xPangkat naik ⇔ logaritma turun. Contoh: f(x) = 2ᵣ → f⁻¹(x) = 2log x (dibahas tuntas di Materi 5)
f(x) = x², x ≥ 0f⁻¹(x) = √xKuadrat ⇔ akar; syarat x ≥ 0 wajib agar bijektif
f(x) = √xf⁻¹(x) = x², x ≥ 0Kebalikan baris sebelumnya — domain dan range bertukar
f(a) = bf⁻¹(b) = aTukar instan tanpa mencari rumus. Contoh: f(4) = 9 → f⁻¹(9) = 4

Rumus pecahan berlaku untuk fungsi homografik (c ≠ 0, dan ad − bc ≠ 0 agar bijektif). Untuk bentuk lain, kembalilah ke empat langkah Materi 2.

Dari mana rumus pecahan? Terapkan empat langkah pada y = (ax + b)/(cx + d): tukar variabel → x(cx + d) = ay + b → cxy + dx = ay + b → y(cx − a) = −dx + b → y = (−dx + b)/(cx − a). Rumus "ajaib" itu ternyata lahir dari empat langkah yang sama — jika lupa, turunkan sendiri dalam 30 detik!

Materi 4 · Komposisi Fungsi

Invers dari Komposisi Fungsi

Ingat kembali: (f∘g)(x) = f(g(x)) artinya g bekerja dulu, baru f. Ketika komposisi dibalik dengan invers, urutan kerjanya juga ikut terbalik — seperti melepas sepatu dan kaus kaki.

(f∘g)⁻¹ = g⁻¹∘f⁻¹
urutan terbalik: f⁻¹ bekerja dulu, baru g⁻¹ — untuk tiga fungsi: (f∘g∘h)⁻¹ = h⁻¹∘g⁻¹∘f⁻¹

Analogi Sepatu & Kaus Kaki

Memakai: kaus kaki dulu (g), lalu sepatu (f). Untuk kembali ke kondisi awal, urutannya harus dibalik: lepas sepatu dulu (f⁻¹), baru kaus kaki (g⁻¹). Salah urutan = tidak kembali ke asal. Itulah mengapa (f∘g)⁻¹ = g⁻¹∘f⁻¹, bukan f⁻¹∘g⁻¹.

Dua teknik menghitung (hasilnya selalu sama):
Teknik A — hitung komposisinya dulu, lalu inverskan.
Teknik B — inverskan masing-masing, lalu susun terbalik.

Contoh Lengkap Dua Cara

Diketahui f(x) = 2x + 3 dan g(x) = x − 1. Cari (f∘g)⁻¹(x).

Teknik A: (f∘g)(x) = 2(x − 1) + 3 = 2x + 1 → (f∘g)⁻¹(x) = (x − 1)/2
Teknik B: f⁻¹(x) = (x − 3)/2 dan g⁻¹(x) = x + 1 → g⁻¹(f⁻¹(x)) = (x − 3)/2 + 1 = (x − 3 + 2)/2 = (x − 1)/2 ✓

Dua jalan berbeda, satu jawaban — gunakan yang kedua untuk mengecek yang pertama.

Mencari fungsi yang hilang — dua rumus pembuka banyak soal: jika (f∘g)(x) dan f diketahui, maka g(x) = f⁻¹((f∘g)(x)) (lewat invers f dulu). Jika (f∘g)(x) dan g diketahui, maka f(x) = (f∘g)(g⁻¹(x)) (lewat invers g dulu). Logikanya: untuk "membongkar" komposisi, kita bongkar dengan invers fungsi terluarnya.

Materi 5 · Logaritma

Fungsi Logaritma: Invers dari Fungsi Eksponen

Fungsi eksponen f(x) = aᵣ (a > 0, a ≠ 1) memetakan pangkat → hasil. Logaritma menjawab pertanyaan sebaliknya: "a harus dipangkatkan berapa agar menjadi bilangan ini?" Karena arahnya berlawanan, logaritma adalah fungsi invers dari eksponen.

Definisi & Jembatan Konversi

aᵗ = y  ⇔  alog y = x
contoh: 2³ = 8 ⇔ 2log 8 = 3 ("2 pangkat berapa = 8? jawab: 3")
Bentuk eksponenBentuk logaritma
2³ = 82log 8 = 3
5⁻² = 1/255log (1/25) = −2
10¹ = 1010log 10 = 1
a¹ = aalog a = 1

Sebagai Pasangan Invers

Fungsi f(x) = aᵣ dan f⁻¹(x) = alog x saling membatalkan:

a(alog x) = x   dan   alog(aᵗ) = t

Contoh: 2(2log 32) = 32 karena 2log 32 = 5. Sifat domain–range juga bertukar persis seperti Materi 1:

f(x) = aᵣf⁻¹(x) = alog x
Domainsemua x ∈ ℝx > 0
Rangey > 0semua y ∈ ℝ

Inilah sebab grafik logaritma hanya ada di kanan sumbu Y (x > 0): argumen logaritma harus positif.

Kenapa a ≠ 1? Jika a = 1, maka 1ᵣ = 1 untuk semua x — pemetaan banyak-ke-satu (tidak injektif), sehingga tidak punya invers. Jika a = 0 atau a < 0, nilainya tidak terdefinisi untuk banyak pangkat. Syarat a > 0 dan a ≠ 1 menjamin f bijektif — persis syarat invers di Materi 1.

Grafik Eksponen & Logaritma: Cermin y = x

Pilih basis a, lalu amati kurva eksponen y = aᵣ (biru), kurva logaritma y = alog x (oranye), dan garis cermin y = x (abu-abu putus-putus). Kedua kurva selalu saling bercermin — bukti visual bahwa logaritma adalah invers eksponen.

Simulasi 4 · Jelajah Grafik Logaritma

Klik salah satu tombol basis untuk menggambar kurvanya.

Titik-Titik Kunci

Grafik y = alog x selalu melalui (1, 0) dan (a, 1) — karena alog 1 = 0 dan alog a = 1. Grafik y = aᵣ melalui (0, 1) dan (1, a). Pasangan titiknya saling bertukar koordinat — ciri khas pasangan invers!

Naik atau Turun?

Jika a > 1: kedua kurva monoton naik (semakin besar input, semakin besar output). Jika 0 < a < 1: kedua kurva monoton turun. Grafik logaritma juga menjauhi garis vertikal x = 0 (asimtot tegak) karena domainnya x > 0.

Materi 5 · Sifat-Sifat

Sifat-Sifat Logaritma untuk Perhitungan Cepat

Sifat-sifat berikut lahir langsung dari hubungan invers dengan eksponen. Kuasai sifat dasar untuk membaca nilai, dan sifat operasi untuk menggabungkan logaritma.

Sifat Dasar

alog 1 = 0   karena a⁰ = 1
alog a = 1   karena a¹ = a
alog aⁿ = n   langsung baca pangkatnya
a(alog x) = x   eksponen membatalkan log (invers!)

Contoh cepat: 2log 16 = 4 (karena 2⁴ = 16) · 5log (1/125) = −3 (karena 5⁻³ = 1/125) · 3(3log 10) = 10.

Sifat Operasi

alog(xy) = alog x + alog y
alog(x/y) = alog x − alog y
alog xⁿ = n · alog x

Contoh: 3log 27 − 3log 3 = 3 − 1 = 2 · 2log 48 = 2log(16 × 3) = 4 + 2log 3 · 2log 5 × 5log 8 = 2log 8 = 3 (logaritma tengah "saling menghapus" — sifat perubahan basis).

Hubungan dengan invers: setiap sifat di atas bisa diturunkan dengan menulis ulang logaritma menjadi eksponen. Contoh: alog(xy) = p berarti aᵗ = x dan aᵟ = y, sehingga aᵗ⁺ᵟ = xy, yang berarti alog(xy) = t + u = alog x + alog y. Logaritma mengubah perkalian menjadi penjumlahan — itulah alasan historisnya logaritma dipakai untuk mempercepat perhitungan.

HOTS #1 & #2: Ketika Soal Memberi Output dan Menanya Input

Ciri khas soal HOTS tentang invers: model fungsinya jelas, tetapi arah pertanyaannya dibalik — yang diketahui hasilnya (output), yang ditanya penyebabnya (input). Di situlah fungsi invers bekerja. Buka pembahasannya langkah demi langkah.

HOTS 1 · Jarak Terjauh dari Budget (Ojek Online)

HOTS 2 · Oven dari Buku Resep Impor
Soal: resep kue dari buku luar negeri menyuruh memanggang pada 410°F, tetapi oven di rumah menampilkan Celsius. Rumus konversi: F = (9/5)C + 32. Suhu berapa (dalam °C) yang harus diatur?

Strategi mengenali soal invers: tandai dulu mana input dan mana output dalam model. "Harga dari jarak" berarti jarak = input. Jika soal memberi harga dan menanya jarak, kamu sedang diminta menghitung f⁻¹(harga) — meskipun soal tidak pernah menulis notasi invers sekalipun.

HOTS #3–#5: Ketika Inversnya Berupa Logaritma

Pertumbuhan, keaslian, kekuatan gempa, dan bunga majemuk semuanya dimodelkan secara eksponensial. Menanya "kapan?" atau "seberapa besar?" berarti membalik eksponen — dan balikannya adalah logaritma.

HOTS 4 · pH dan Skala Gempa (Pembahasan Kilat)

pH larutan: pH = −log[H⁺]. Larutan A bersifat asam dengan pH 3 → [H⁺] = 10⁻³ M; larutan B dengan pH 5 → [H⁺] = 10⁻⁵ M. Larutan A 100 kali lebih asam. Kimiawan bekerja dua arah: dari konsentrasi ke pH (logaritma), dan dari pH ke konsentrasi lewat inversnya, [H⁺] = 10⁻ᵗᴸ (eksponen).

Skala Richter: M = 10log(A/A₀). Gempa M = 4 berarti amplitudonya 10⁴ × A₀; M = 6 berarti 10⁶ × A₀. Selisih 2 skala = amplitudo 100 kali, dan energinya kira-kira 1.000 kali. Skala logaritmik memampatkan rentang angka yang sangat lebar menjadi sederhana.

Mengapa logaritma cocok untuk fenomena alam? Karena indera dan banyak proses alami merespons perbandingan, bukan selisih: gempa 100× lebih kuat terasa "dua tingkat", larutan 100× lebih asam turun "dua poin pH". Inversi logaritma-lah yang menerjemahkan antara kedua dunia itu.
HOTS 5 · Berapa Lama Menabung Agar Capai Target?
Soal: Pak Rahmat menyetor deposito Rp2.000.000 dengan bunga majemuk 10% per tahun (bunga masuk tiap akhir tahun), sehingga saldonya A(n) = 2.000.000 × (1,1)ⁿ. Berapa tahun sampai saldonya mencapai Rp3.200.000? (Diketahui 10log 1,6 ≈ 0,2041 dan 10log 1,1 ≈ 0,0414.)

Penutup

Kesimpulan

Enam bekal utama dari materi Fungsi Invers yang harus selalu kamu ingat saat mengerjakan soal TKA.

Definisi & Syarat

f(a) = b ⇔ f⁻¹(b) = a. Invers hanya ada jika f bijektif (injektif + surjektif). Domain dan range bertukar peran: D(f⁻¹) = R(f). Dan ingat selalu: f⁻¹(x) ≠ 1/f(x) — notasi −1 berarti pemetaan balik, bukan kebalikan nilai.

Empat Langkah Emas

(1) misalkan y = f(x); (2) tukar x dan y; (3) selesaikan untuk y; (4) tulis f⁻¹(x). Selalu verifikasi dengan f(f⁻¹(x)) = x. Untuk fungsi kuadrat dan akar, pembatasan domain menentukan tanda jawaban yang sah.

Rumus Cepat

Linear: f(x) = ax + b → f⁻¹(x) = (x − b)/a. Pecahan: f(x) = (ax + b)/(cx + d) → f⁻¹(x) = (−dx + b)/(cx − a). Komposisi ax + b memakai rumus yang sama. Eksponen ⇔ logaritma, kuadrat ⇔ akar.

Invers Komposisi

(f∘g)⁻¹ = g⁻¹∘f⁻¹ — urutan terbalik (analogi sepatu–kaus kaki). Mencari fungsi yang hilang: g(x) = f⁻¹((f∘g)(x)) dan f(x) = (f∘g)(g⁻¹(x)). Hubungan f(a) = b ⇔ f⁻¹(b) = a menyelesaikan soal nilai tanpa rumus panjang.

Logaritma & Grafik

alog y = x ⇔ aᵗ = y; logaritma adalah invers eksponen. Grafik y = alog x melalui (1, 0) dan (a, 1), domain x > 0, cermin y = aᵣ terhadap garis y = x. Naik jika a > 1, turun jika 0 < a < 1. Sifat: alog 1 = 0, alog a = 1, alog aⁿ = n.

HOTS: Kenali Arahnya

Pada masalah nyata, tandai dulu mana input dan output. "Output diketahui, input ditanya" = pekerjaan invers: tarif → jarak, harga akhir → harga awal, target bakteri → waktu (lewat logaritma), pH → konsentrasi (lewat eksponen). Perhatikan konteks pembulatan tahun/jam.
