3 Ingat-Ingat

🔗 Definisi Relasi

Relasi adalah aturan yang menghubungkan setiap anggota himpunan A (domain) dengan anggota himpunan B (kodomain). Satu anggota A boleh berelasi dengan banyak anggota B.

🔗 Definisi Fungsi

Fungsi adalah relasi khusus di mana setiap anggota A TEPAT memiliki satu pasangan di B. Tidak boleh ada anggota A yang punya dua pasangan di B.

DOMAIN (Df)
Daerah Asal

Anggota himpunan A yang dipetakan

KODOMAIN (K)
Daerah Kawan

Anggota himpunan B tempat pemetaan

RANGE (Rf)
Daerah Hasil

Anggota B yang menjadi pasangan A

Cara Menyatakan Fungsi:

4️⃣ Rumus / Persamaan f(x) = ...

4 Domain Suatu Fungsi
🎯 Cara menentukan daerah asal

Cara Mencari Domain Suatu Fungsi

Domain (Daerah Asal) adalah himpunan semua nilai x yang membuat fungsi terdefinisi (tidak menghasilkan pembagian nol atau akar kuadrat negatif).

1. Fungsi Aljabar / Polinom

Bentuk: y = f(x)

Domain: x ∈ ℝ
Contoh: f(x) = 2x + 1 atau f(x) = x² - 3
2. Fungsi Pecahan (Rasional)

Bentuk: y = f(x) / g(x)

Syarat: g(x) ≠ 0
Contoh: f(x) = 1 / (x - 3) ⇒ x - 3 ≠ 0 ⇒ x ≠ 3
3. Fungsi Akar

Bentuk: y = √f(x)

Syarat: f(x) ≥ 0
Contoh: f(x) = √(2x + 6) ⇒ 2x + 6 ≥ 0 ⇒ x ≥ -3
4. Pecahan dengan Akar Penyebut

Bentuk: y = f(x) / √g(x)

Syarat: g(x) > 0
Contoh: f(x) = 1 / √(x - 2) ⇒ x - 2 > 0 ⇒ x > 2
5. Akar di Pembilang Pecahan

Bentuk: y = √f(x) / g(x)

Syarat: f(x) ≥ 0 dan g(x) ≠ 0
Contoh: f(x) = √x / (x - 1) ⇒ x ≥ 0 dan x ≠ 1
6. Penjumlahan Akar

Bentuk: y = √f(x) ± √g(x)

Syarat: f(x) ≥ 0 dan g(x) ≥ 0
Contoh: f(x) = √(x-2) + √(4-x) ⇒ x ≥ 2 dan x ≤ 4

📝 Latihan: Tentukan Domain!

5 Kodomain & Range
🎯 Daerah Kawan & Hasil

Cara Mencari Kodomain dan Range

1. Dari Diagram Panah

  • Kodomain: Semua anggota himpunan B (kanan).
  • Range: Anggota himpunan B yang menjadi tujuan panah.

2. Dari Persamaan

  • Range: Substitusi nilai domain ke f(x).
  • Jika y = f(x), maka range adalah himpunan semua y yang terbentuk.

💡 Contoh:

Diketahui f(x) = x² dengan domain { -1, 0, 1, 2 }.

f(-1) = (-1)² = 1
f(0) = 0² = 0
f(1) = 1² = 1
f(2) = 2² = 4
Range = { 0, 1, 4 }

*Jika domainnya semua bilangan real ℝ dan f(x) = x², maka range-nya adalah { y | y ≥ 0 }.

6 Operasi Aljabar Fungsi
7 Jenis-jenis Fungsi
🚀 Keluarga Besar Fungsi
1️⃣

Fungsi Ganjil

f(-x) = -f(x)

Contoh: f(x) = x³ atau f(x) = sin(x).
Grafik simetris terhadap titik origin (0,0).

2️⃣

Fungsi Genap

f(-x) = f(x)

Contoh: f(x) = x² atau f(x) = cos(x).
Grafik simetris terhadap sumbu Y.

3️⃣

Fungsi Injektif (Satu-satu)

Trik: Kodomain tidak boleh selingkuh!

Tidak ada dua anggota domain yang memetakan ke anggota kodomain yang sama.

4️⃣

Fungsi Surjektif (Onto)

Trik: Kodomain tidak ada jomblo!

Semua anggota kodomain menjadi pasangan dari domain (range = kodomain).

5️⃣

Fungsi Bijektif

Trik: Tidak selingkuh dan tidak jomblo!

Fungsi yang injektif sekaligus surjektif. Memiliki pasangan invers (kebalikan).

9 Pembahasan PR
📚 Mari koreksi bersama

📖 Pembahasan PR Rumah

Soal 1: Domain

Tentukan domain dari f(x) = √(x - 5)

Syarat: Upari ≥ 0
x - 5 ≥ 0
x ≥ 5

Soal 2: Operasi

Diketahui f(x) = 2x dan g(x) = x + 3. Tentukan (f∘g)(x)

(f∘g)(x) = f(g(x))
= f(x + 3)
= 2(x + 3)
= 2x + 6

Soal 3: Jenis Fungsi

Apakah f(x) = x³ + x fungsi ganjil atau genap?

f(-x) = (-x)³ + (-x)
= -x³ - x
= -(x³ + x)
= -f(x)
Karena f(-x) = -f(x), maka ini Fungsi Ganjil

Soal 4: Range

Diketahui f(x) = 2x + 1 dengan domain {0, 1, 2}. Range?

f(0) = 2(0) + 1 = 1
f(1) = 2(1) + 1 = 3
f(2) = 2(2) + 1 = 5
Range = {1, 3, 5}
