Materi: Operasi pada Fungsi

Rangkuman singkat tentang komposisi fungsi untuk membantumu mengerjakan soal.

Pengertian Komposisi Fungsi

Komposisi fungsi adalah penggabungan dua fungsi atau lebih sehingga menghasilkan fungsi baru. Jika f dan g adalah dua fungsi, maka komposisi f oleh g ditulis:

(f ∘ g)(x) = f(g(x))

Artinya: masukkan g(x) sebagai input dari fungsi f.

Urutan Operasi

Penting Komposisi fungsi tidak komutatif, artinya:

(f ∘ g)(x) ≠ (g ∘ f)(x)

(f ∘ g)(x) berarti kerjakan g dulu, lalu hasilnya dipakai di f. (g ∘ f)(x) berarti kerjakan f dulu, lalu di g.

Menentukan Rumus Komposisi

Contoh: f(x) = 2x + 3 dan g(x) = x − 1. Maka:

(f ∘ g)(x) = f(g(x)) = f(x − 1) = 2(x − 1) + 3 = 2x + 1

Substitusikan seluruh argumen fungsi luar ke variabel fungsi dalam.

Mencari Fungsi Komponen

Jika (f ∘ g)(x) dan g(x) diketahui, untuk mencari f(x):

  • Misalkan g(x) = p, lalu nyatakan x dalam p
  • Substitusi ke (f ∘ g)(x) untuk mendapatkan f(p)
  • Ganti p menjadi x → f(x)

Contoh: (f ∘ g)(x) = 4x + 2, g(x) = x + 1.
Misal p = x + 1 → x = p − 1. Maka f(p) = 4(p − 1) + 2 = 4p − 2. Jadi f(x) = 4x − 2.

Komposisi Tiga Fungsi

Untuk (f ∘ g ∘ h)(x), kerjakan dari kanan ke kiri:

(f ∘ g ∘ h)(x) = f(g(h(x)))

Hitung h(x) dulu → masukkan ke g → masukkan ke f.

Domain Komposisi

Domain (f ∘ g)(x) adalah semua x di domain g sehingga g(x) berada di domain f. Untuk fungsi akar, syaratnya:

√(g(x)) terdefinisi ⟺ g(x) ≥ 0

Invers Komposisi

Sifat invers komposisi fungsi:

(f ∘ g)⁻¹(x) = (g⁻¹ ∘ f⁻¹)(x)

Selain itu: jika (f ∘ g)⁻¹(a) = b, maka (f ∘ g)(b) = a.

Tips Cepat

  • Untuk soal nilai (f ∘ g)(a), kerjakan g(a) dulu, lalu substitusi ke f.
  • Untuk soal rumus komposisi kuadrat, gunakan identitas (a + b)² = a² + 2ab + b².
  • Periksa domain fungsi pecahan: penyebut ≠ 0. Fungsi akar: radikan ≥ 0.
  • Untuk mencari g(x) dari (g ∘ f)(x), coba nyatakan dalam bentuk f(x) lalu substitusi.
