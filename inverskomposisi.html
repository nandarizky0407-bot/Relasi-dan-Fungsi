Review Materi 1

🔗 Komposisi Fungsi

(f ∘ g)(x) = f(g(x))

Artinya fungsi g dikerjakan lebih dulu, kemudian hasilnya menjadi masukan bagi fungsi f.

Langkah menentukan (f ∘ g)(x)

  1. Tulis bentuk komposisi: (f ∘ g)(x) = f(g(x)).
  2. Substitusikan rumus g(x) ke setiap x pada f(x).
  3. Sederhanakan hasilnya.
Contoh: f(x) = 2x + 1 dan g(x) = x2
(f ∘ g)(x) = f(x2) = 2x2 + 1  •  (g ∘ f)(x) = g(2x + 1) = (2x + 1)2
⚠️ Umumnya (f ∘ g)(x) ≠ (g ∘ f)(x) — urutan komposisi sangat penting!
Review Materi 2

🔁 Invers Fungsi

f(a) = b ⇔ f−1(b) = a

Invers fungsi f−1 "membatalkan" efek fungsi f: memetakan hasil kembali ke asalnya.

Langkah menentukan f−1(x)

  1. Misalkan y = f(x).
  2. Nyatakan x dalam y (pindah ruas / kali silang).
  3. Tulis f−1(x) dengan mengganti y menjadi x.
Contoh: f(x) = 3x − 6
y = 3x − 6 ⇒ 3x = y + 6 ⇒ x = y + 63 ⇒ f−1(x) = x + 63

✅ Syarat Fungsi Memiliki Invers

Fungsi f : A → B memiliki invers f−1 : B → A jika dan hanya jika f merupakan korespondensi satu-satu (bijektif), yaitu memenuhi dua syarat sekaligus:

1️⃣ Injektif (satu-satu) Setiap dua elemen berbeda di A memiliki bayangan yang berbeda di B:
f(a) = f(b) ⇒ a = b
Uji grafik: setiap garis horizontal memotong grafik paling banyak satu kali.
2️⃣ Surjektif (ke atas) Setiap elemen di B memiliki prapeta di A, sehingga range = kodomain — tidak ada anggota B yang "menganggur".
f bijektif = injektif + surjektif ⇔ f memiliki invers f−1
Ilustrasi: f(x) = x2 dengan domain ℝ tidak memiliki invers karena tidak injektif: f(2) = f(−2) = 4. Jika domain dibatasi x ≥ 0, fungsi menjadi satu-satu dan memiliki invers f−1(x) = √x.
📌 Untuk fungsi linear f(x) = ax + b, invers selalu ada selama a ≠ 0 (fungsi konstan tidak punya invers). Fungsi pecahan f(x) = ax+bcx+d juga selalu memiliki invers selama ad − bc ≠ 0.
Review Materi 3

🔑 Sifat-sifat Invers Fungsi

Tiga sifat penting invers fungsi yang sering muncul dalam soal. Klik setiap contoh soal untuk melihat pembahasannya.

Sifat 1 — Sifat Identitas

(f ∘ f−1)(x) = (f−1 ∘ f)(x) = x

Fungsi dan inversnya saling "menghapus": jika x dimasukkan ke f lalu hasilnya dimasukkan ke f−1 (atau sebaliknya), hasilnya kembali ke x semula.

👇 Klik setiap soal untuk melihat pembahasan:

Contoh 1 Diketahui f(x) = 2x + 3 dan f−1(x) = x−32. Tunjukkan bahwa (f ∘ f−1)(x) = (f−1 ∘ f)(x) = x.
(f ∘ f−1)(x) = f(x−32) = 2 · x−32 + 3 = (x − 3) + 3 = x ✓
(f−1 ∘ f)(x) = f−1(2x + 3) = (2x+3)−32 = 2x2 = x ✓
Contoh 2 Diketahui f(x) = 5x − 4. Tanpa mencari rumus f−1(x) terlebih dahulu, tentukan nilai (f ∘ f−1)(7) dan (f−1 ∘ f)(−2).
Berdasarkan sifat identitas, komposisi fungsi dengan inversnya selalu menghasilkan x semula, berapa pun bentuk f-nya.
Jadi, (f ∘ f−1)(7) = 7 dan (f−1 ∘ f)(−2) = −2.
Contoh 3 Diketahui f(x) = x+1x−2, x ≠ 2. Tentukan nilai (f ∘ f−1)(10).
Dengan sifat identitas: (f ∘ f−1)(10) = 10.
Verifikasi: f−1(x) = 2x+1x−1 ⇒ f−1(10) = 219 = 73, lalu f(73) = 7/3 + 17/3 − 2 = 10/31/3 = 10 ✓
Contoh 4 Diketahui f−1(x) = 3x−12 dan berlaku (f−1 ∘ f)(x) = x. Tentukan rumus f(x).
Karena f dan f−1 saling menghapus, maka f adalah invers dari f−1.
y = 3x−12 ⇒ 2y = 3x − 1 ⇒ 3x = 2y + 1 ⇒ x = 2y+13
Jadi, f(x) = 2x+13.
Cek: (f−1 ∘ f)(x) = 3·(2x+1)/3 − 12 = 2x2 = x ✓
Contoh 5 Diketahui f(x) = x2 + 1 untuk x ≥ 0. Tunjukkan bahwa (f ∘ f−1)(x) = x.
Dengan syarat x ≥ 0, fungsi f menjadi injektif sehingga memiliki invers: f−1(x) = √(x − 1), x ≥ 1.
(f ∘ f−1)(x) = (√(x − 1))2 + 1 = (x − 1) + 1 = x ✓ (berlaku untuk x ≥ 1)

Sifat 2 — Invers dari Invers

(f−1)−1(x) = f(x)

Invers dari sebuah fungsi invers mengembalikan fungsi asalnya. Jadi, jika yang diketahui hanya f−1, maka rumus f diperoleh dengan mencari invers dari f−1.

👇 Klik setiap soal untuk melihat pembahasan:

Contoh 1 Diketahui f(x) = 3x − 6 dengan f−1(x) = x+63. Tentukan (f−1)−1(x).
Langsung oleh sifat: (f−1)−1(x) = f(x) = 3x − 6.
Verifikasi: invers dari x+63: y = x+63 ⇒ 3y = x + 6 ⇒ x = 3y − 6 ✓
Contoh 2 Diketahui f−1(x) = x−45. Tentukan rumus f(x).
f(x) = (f−1)−1(x), yaitu invers dari x−45.
y = x−45 ⇒ 5y = x − 4 ⇒ x = 5y + 4
Jadi, f(x) = 5x + 4.
Contoh 3 Diketahui g−1(x) = 2x − 7. Tentukan nilai g(4).
g(x) = (g−1)−1(x) = invers dari 2x − 7.
y = 2x − 7 ⇒ x = y+72 ⇒ g(x) = x+72
g(4) = 4+72 = 112 = 5,5
Contoh 4 Diketahui h−1(x) = 5x + 2. Tentukan nilai (h−1)−1(3).
Menurut sifat: (h−1)−1(3) = h(3).
h(x) = invers dari 5x + 2 = x−25, maka h(3) = 3−25 = 15.
Contoh 5 Diketahui f(x) = 2x−1x+3, x ≠ −3. Tentukan (f−1)−1(x) dan tunjukkan hasilnya kembali ke f(x).
Cari f−1 dulu: y = 2x−1x+3 ⇒ y(x + 3) = 2x − 1 ⇒ xy − 2x = −1 − 3y ⇒ x(y − 2) = −(1 + 3y)
f−1(x) = 3x+12−x, x ≠ 2.
Lalu invers dari f−1: y = 3x+12−x ⇒ y(2 − x) = 3x + 1 ⇒ 2y − 1 = x(y + 3) ⇒ x = 2y−1y+3
Hasilnya = 2x−1x+3 = f(x) ✓

Sifat 3 — Sifat Invers pada Fungsi Komposisi

(g ∘ f)−1(x) = (f−1 ∘ g−1)(x)   dan   (f ∘ g)−1(x) = (g−1 ∘ f−1)(x)

Invers dari komposisi adalah komposisi invers dengan urutan terbalik. Analogi: memakai kaus kaki lalu sepatu — untuk melepasnya, sepatu dilepas dulu, baru kaus kaki.

👇 Klik setiap soal untuk melihat pembahasan:

Contoh 1 Diketahui f(x) = 2x + 1 dan g(x) = x − 3. Tentukan (g ∘ f)−1(x) dengan sifat invers komposisi, lalu verifikasi dengan cara langsung.
Dengan sifat: f−1(x) = x−12 dan g−1(x) = x + 3.
(g ∘ f)−1(x) = (f−1 ∘ g−1)(x) = f−1(x + 3) = (x+3)−12 = x+22
Verifikasi: (g ∘ f)(x) = g(2x + 1) = 2x − 2 ⇒ inversnya x+22 ✓
Contoh 2 Diketahui f−1(x) = x−23 dan g−1(x) = 2x + 1. Tentukan (g ∘ f)−1(x).
(g ∘ f)−1(x) = (f−1 ∘ g−1)(x) = f−1(2x + 1) = (2x+1)−23 = 2x−13
Contoh 3 Diketahui f(x) = 3x dan g(x) = x+25. Tentukan (g ∘ f)−1(x).
Dengan sifat: f−1(x) = x3 dan g−1(x) = 5x − 2.
(g ∘ f)−1(x) = f−1(5x − 2) = 5x−23
Verifikasi: (g ∘ f)(x) = g(3x) = 3x+25 ⇒ 5y = 3x + 2 ⇒ x = 5y−23 ✓
Contoh 4 Diketahui f(x) = 2x + 1 dan g(x) = 3x. Tentukan (f ∘ g)−1(x) menggunakan sifat (f ∘ g)−1(x) = (g−1 ∘ f−1)(x).
f−1(x) = x−12 dan g−1(x) = x3.
(f ∘ g)−1(x) = g−1(x−12) = x−16
Verifikasi: (f ∘ g)(x) = f(3x) = 6x + 1 ⇒ inversnya x−16 ✓
Contoh 5 Diketahui (g ∘ f)−1(x) = x+45 dan f−1(x) = x+15. Tentukan rumus g−1(x).
Dengan sifat: (g ∘ f)−1(x) = (f−1 ∘ g−1)(x) = f−1(g−1(x)) = g−1(x) + 15
Maka: g−1(x) + 15 = x+45 ⇒ g−1(x) + 1 = x + 4
Jadi, g−1(x) = x + 3.
Cek: f(x) = 5x − 1 dan g(x) = x − 3 ⇒ (g ∘ f)(x) = 5x − 4 ⇒ inversnya x+45 ✓
Review Materi 4

🌍 Fungsi dalam Kehidupan Sehari-hari

Banyak kejadian sehari-hari dimodelkan dengan fungsi, dan invers dipakai untuk mencari "masukan" dari suatu "hasil".

🚕 Tarif Taksi OnlineB(x) = 4.500x + 8.000. Inversnya B−1 digunakan untuk mencari jarak tempuh dari biaya yang dibayar.
🌡️ Konversi SuhuF = 95C + 32. Inversnya: C = 59(F − 32) untuk mengubah Fahrenheit ke Celcius.
🏭 Produksi Dua TahapHasil mesin tahap I menjadi masukan mesin tahap II — modelnya komposisi (g ∘ f)(x).
💰 Gaji + KomisiP(x) = gaji pokok + 5% × penjualan. Invers P−1 mencari target penjualan dari total gaji.
🦠 Pertumbuhan BakteriN(t) = N₀ · 2t. Inversnya menentukan waktu t dari populasi yang diketahui.
💱 Konversi Mata UangRupiah → Dolar → Yen merupakan komposisi dua fungsi konversi.
